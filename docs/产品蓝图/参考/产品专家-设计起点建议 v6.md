**结论：**
- **首推定稿：** 六类一开始就推，主人随时可以关。原来五类：设备看不见狗了；狗出了门、不见了；持续异常叫嚎；翻垃圾或啃危险东西；被困住出不来。新增第六类：疑似急症（反复呕吐、倒地抽动、长时间不动）。第六类只说画面里看到了什么、建议联系兽医，不判断病情。
- **人到狗，从训犬师真实的做法出发：** 训犬师做的事，大半是在管住人自己：信号只用一个词、只说一遍，奖励要快，一次只教一小步，先管好环境不让狗犯错，记录到了哪一步，卡住就退回去。主人做不到，难点也有资料：注意不到狗做对的时刻，口令被自己用坏了，以为狗已经懂了，建议太多做不完。产品能帮的，每一条都对得上这些做法或难点（第三节第四部分）。
- **训犬之外：**「要出门了」有研究支持保持出门信号一致；「没事」靠主人做出来，比说出来管用；「到时间了」没有查到狗能理解时间词的证据，能做的是固定作息和固定的结束信号。
- **v5 的「五步诊断」和「主人拍互动视频」切入点已删除。**

## 一、沿用的框架（简述）

- 狗不看屏幕，产品的每一句话都是说给主人听的。主人想知道时自己来看，是「拉」；产品发现了事情主动找主人，是「推」（详见 v4 第二至四节，仓库分支历史 `211c9c3`）。
- 先只服务主人。家人、寄养人、训练师、兽医以后再议。下文资料里涉及「全家口令统一」的内容，只当作主人自己会遇到的难点，不把家人当成产品用户。

### 六类首推

| 类别 | 理由 | 误报怎么处置 |
|---|---|---|
| **P1 设备看不见狗了**：摄像头离线、录像中断、画面被挡 | 主人会把「没推送」误当成「没事」。有证据：设备离线四小时也没收到通知（O3，仓内 [docs/方向调研/产品专家-A用户证据v0.md](../../%E6%96%B9%E5%90%91%E8%B0%83%E7%A0%94/%E4%BA%A7%E5%93%81%E4%B8%93%E5%AE%B6-A%E7%94%A8%E6%88%B7%E8%AF%81%E6%8D%AEv0.md) 第 29 行，摘录） | 短暂抖动不推，持续中断才推（多久算中断，推断，待定）；恢复时补一条「已恢复」 |
| **P2 狗出了门、不见了** | 走失几乎无法挽回，时效以分钟计（往外跑是常见行为问题，Salman 等 1998，v1 已记录） | 附出门那几秒的画面；主人点「是我开的门」或「它在别的房间」后，记住这个家的正常出入方式 |
| **P3 持续异常叫嚎**：持续时间或强度明显超出这只狗平时的范围 | 主人不在家听不到；邻居投诉已有个案（团团案，仓内 [market/insights.md](../../../market/insights.md) 第 16 行，单方自述）。只看声音持续多久、多响，不判断原因 | 电视声、外面的狗可能被误认（Furbo 官方承认，仓内 [docs/方向调研/产品专家-用户证据v0.md](../../%E6%96%B9%E5%90%91%E8%B0%83%E7%A0%94/%E4%BA%A7%E5%93%81%E4%B8%93%E5%AE%B6-%E7%94%A8%E6%88%B7%E8%AF%81%E6%8D%AEv0.md) 第 40 行）；同一段只推一次；主人点「没事」后，这个家的门槛跟着调高 |
| **P4 翻垃圾、啃危险东西** | 误食后果可能很重。有证据：狗吃掉整个披萨，1 小时 40 分钟后主人才收到提醒（O2，仓内 [docs/方向调研/产品专家-A用户证据v0.md](../../%E6%96%B9%E5%90%91%E8%B0%83%E7%A0%94/%E4%BA%A7%E5%93%81%E4%B8%93%E5%AE%B6-A%E7%94%A8%E6%88%B7%E8%AF%81%E6%8D%AEv0.md) 第 28 行，摘录） | 只报看到了什么，不说吃了会怎样；主人点「那是它的玩具」后，记住这件东西 |
| **P5 被困住出不来**：长时间在同一处扒门、挣扎，伴随哀叫 | 主人不在场时没人能发现（推断，仓内没有个案） | 门槛定严，宁可晚推几分钟；附画面让主人自己判断 |
| **P6 疑似急症**：反复呕吐、倒地抽动、长时间不动 | 满足 J1–J6。晶晶 11-16 定为首推 | 见下 |

### P6 疑似急症的边界和误报处置

**能说什么（推断，写法待定）：** 只说画面里看到的事实、次数和时间，再加一句建议。例如：「14:02 到 14:20 之间，画面里看到它呕吐了 3 次。建议联系兽医。点开看这几段画面。」

**不能说什么：**
- 不说可能是什么病、严不严重、要不要紧，也不说「应该没事」。
- 不给处理办法（喂水、催吐、用药这类），只建议联系兽医。
- 没推送不等于狗健康。产品要在主人开启时说清楚：它只会在画面里看到这几种情况时提醒，看不到的、画面外的、不明显的都发现不了。这一条防止主人把首推当成健康监测（README 第 6–7 行的边界）。
- 不拿急症推送带货，不推荐药品、保险或诊所。

**三种情况各自的误报来源和处置（全部是推断，没有频率数据）：**

| 情况 | 容易被误认的 | 处置 |
|---|---|---|
| 反复呕吐 | 吃草后吐一次、咳嗽、甩头、干呕一次 | 只有多次才推（几次算「反复」，待定）；推送附每一次的画面片段；主人点「它常这样」后，只对这只狗调高门槛，不永久关掉 |
| 倒地抽动 | 睡梦中腿抽动、打滚玩、挠痒 | 门槛定严；画面附上倒地前后几秒；主人点「它在做梦」后，记住这只狗平时睡觉的位置和姿势 |
| 长时间不动 | 正常睡觉，尤其老狗和白天 | 不动时间要远超这只狗平时的睡眠片段，而且位置或姿势不寻常才推（比如倒在平时不睡的地方）；第一次推送前，先用这只狗前几天的画面学它的作息 |

**共同规则：**
- 同一次只推一条，后续合并进同一条；主人点开后可以直接看实时画面。
- 画面看不清或狗离开画面时，不猜，转成 P1 或不推。
- 主人每次点「没事」都是反馈，但急症类不允许因为一次「没事」就整类关掉，要主人自己去设置里关（推断：防止一次误报后永远收不到真事件）。

### 所有首推类别的共同规则（沿用 v5）

- 默认开，主人随时可以关掉任何一类。
- 每条推送一句话说清：看到了什么、有几分把握、建议做什么。点开直接看那几秒画面。
- 同一件事只推一次，后续合并。
- 只报看得见的状况，不报情绪和原因。

**刻意没放进首推的（沿用 v5）：** 情绪类（无聊、焦虑、想你）、日常请求、「它在门口等你」。

### 2. 训犬师实际在做的事（只列资料里有的）

| # | 做法 | 资料里怎么说 | 出处 |
|---|---|---|---|
| T1 | **先教一个标记词**，让它等于「好事要来了」 | 狗不需要做任何事，说「Nice」立刻给食物，一周内狗就明白；之后用它标记狗正在做的对的事 | GDF 标记词；GoodDoi 标记训练（「充电」10–20 次） |
| T2 | **一个行为只用一个口令，只说一遍** | 先叫名字再给口令；只说一次，重复只会教狗忽略你；一次一个口令；用释放词「OK」结束，不用表扬结束 | GDF 有效的口令；AKC 训犬师建议（「down」不能同时表示趴下和下沙发）；haipaw、GoodDoi |
| T3 | **语调清楚、平静，按狗的状态调** | 不吼、不含糊；想让狗活泼就用兴奋语调，狗太兴奋就用低平语调 | GDF 有效的口令 |
| T4 | **奖励要快，标记要准** | 标记那一瞬间；奖励晚了，狗会以为奖励的是后来的动作 | GoodDoi 标记训练；haipaw（三秒内）；Browne 2015（晚 1 秒学会率从 60% 降到 25%） |
| T5 | **拆小步，一次只练一个标准** | 每一步都要让狗有现实的机会拿到奖励；一次只训一个标准；加新标准时暂时放松旧的 | Pryor 原则 2–4 |
| T6 | **不让狗干等** | 训练中间别接电话、别聊天；狗没信息可用时会用别的动作填空，甚至出现因压力引起的替代行为 | Pryor 原则 6、8 及文中解释 |
| T7 | **卡住就退回去** | 行为退步时，回到上一两个成功的步骤；一种方法不行就换一种 | Pryor 原则 5、7；AKC 口令被用坏（「回到狗上次成功的那一步」） |
| T8 | **短练、见好就收** | 每次几分钟，在狗还想继续时结束 | Pryor 原则 10；AKC 幼犬五个口令（5–10 分钟）；haipaw（3–5 分钟） |
| T9 | **先管好环境，不让狗有机会犯错** | Dunbar 列的常见错误第一条是「让狗有机会犯错」：谁把憋着尿的狗单独留在卧室？用固定的圈养时间表保证「零失误」如厕和啃咬训练。CCPDT 也把先排查健康和环境、先调整前因放在奖励训练之前 | Dunbar 第 13 页；CCPDT |
| T10 | **在日常里抓狗做对的时刻** | 「Get SMART」：每天从狗粮里数出 50 粒，一看到狗安静趴着、路过鞋子不叼、被叫名字时看你，就说「Nice」给一粒，当天用完。这个练习存在的目的，是帮寄养人学会注意到该奖励的时刻 | GDF Get SMART |
| T11 | **按阶段记录，到点求助** | 每项技能分「入门」「熟练」「维持」三段，各有大致时间；如厕用记录表排时间；到某个时间还没做到（比如进笼两周还不安定），就联系寄养顾问 | GDF 学习顺序 |
| T12 | **泛化：一次只加一种难度** | 在家会、在课上不会是正常的；距离和干扰一次只加一个；先在安静地方，再逐步加干扰 | GDF 幼犬课；haipaw 干扰分级；寵新誌 |
| T13 | **保护重要口令不被用坏** | 不要叫狗过来再骂它、洗澡、剪指甲；不要每次叫回来都扣绳结束玩耍。Dunbar 的做法是在公园里每隔一会儿叫回来、给几粒狗粮、再放它去玩 | Dunbar 第 58、132–133 页；GDF 召回；GoodDoi |
| T14 | **只用奖励式方法** | 用奖励和管理环境，不用惩罚；Dunbar 写道，频繁惩罚说明训练方法本身有问题 | AVSAB 2021；CCPDT；Dunbar 第 53–54 页 |
| T15 | **教主人，而不是只训狗** | 客户中心的沟通方式（不评判，共同商定方案，持续支持）和更高的依从率相关；作业要清楚、跟日常相关，每天两三次 10 分钟能完成 | 2023 JVEB；[traincanine](https://www.traincanine.com/simple-tricks-to-help-dog-training-clients-succeed/)（检索摘录） |

### 5. 训犬之外的人到狗沟通

### 6. 洞察

**洞察 1（有证据，产品结论是推断）：训犬师先训练的是人的眼睛。** 导盲犬机构专门设计 Get SMART，让寄养人每天数出 50 粒狗粮，在狗安静、守规矩时奖励，目的是让人学会注意到这些时刻（GDF）。Dunbar 也把「狗做对了没奖励」列为常见错误。家里的摄像头看到的「狗做对了」比主人多得多，这可能是产品在人到狗这一块最自然的位置：不是教狗，是帮主人看见。

**洞察 2（有证据）：「叫不回来」多半是口令被主人自己用坏了，不是狗笨。** 叫过来就扣绳回家、叫过来挨骂，几次之后狗就会慢慢走，最后不来（Dunbar 第 132 页；AKC；GoodDoi）。主人最常抱怨的「它不听话」，第一个要查的是这个词后面通常跟着什么。

**洞察 3（有证据）：给主人的建议，少比多有效。** 拿到超过 5 条医嘱的主人，狗改善的比例明显更低；主人只照做省时间的（Takeuchi 2000）。产品每次只给一两件事，不是简化，而是有效的前提。

**洞察 4（有证据，单项研究）：「没事」要做出来，光说没用。** 狗遇到奇怪的东西会回头看主人，但主人的语气和表情影响不大，主人往哪走，狗就往哪走（Merola 2012）。

**洞察 5（有证据，但出自观点文章）：出门信号不用藏，要一致。** 以前常劝主人假装出门、打乱信号，有学者认为这反而让狗更不安，建议让出门信号和真实出门对应（Amat 2014）。主人本来也不愿意做脱敏练习（Takeuchi 2000）。

**洞察 6（推断，依据是时机研究）：远程投喂零食可能奖励错了东西。** 奖励晚 1 秒，学会的狗就从 60% 降到 25%（Browne 2015）；隔着网络扔零食，落地时狗可能已经在做别的事。现有摄像头卖点之一的远程投喂，更适合当安心物，不适合拿来训练。

- **产品原则：敢说「你可能看错了」，但要客气、要有画面依据**（晶晶 11-16 定）。写法见 v2 第四节（分支历史 `f92180b`）。人到狗一节的建议也按这个原则表达，并符合 H7。

- **首推六类**（本版定，见第二节）。

## 六、给晶晶拍板的点

1. **人到狗这一块，产品的第一件事定为「帮你看见它做对的时刻」（H4），你同意吗？** 就是用家里的录像告诉你今天它哪些时候表现很好，你下次就知道该在什么时候夸它。它需要拿到录像。
2. **产品每次只给你一两条最省事的建议，做完再给下一条，不一次列一长串（H2），你同意吗？**
3. **「到时间了」这类事，资料里找不到狗能听懂时间的证据。我们只帮你把作息和结束信号固定下来，不做「告诉狗几点了」这类功能，你同意吗？**
