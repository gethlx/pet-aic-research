# 02 · 可行性分析：任务分类与交流假设

> 2026-10-01纠正。原始来源和核查范围见[参考资料 F](04-references.md#f-2026-10-01-原始来源复核与纠正)。区分论文结果、产品验证与研究假设。

## 1. 当前可确认的能力

声学、视觉、IMU、生理传感和上下文可支持明确任务的分类、回归与异常检测。但行为识别、情绪解释、意图推断和临床预警是不同任务，不能互相借用准确率。多模态和个体基线是候选方法，是否优于规则或单模态须比较验证。

| 研究或线索 | 实际任务与结果 | 可支持的结论／限制 |
|---|---|---|
| [U-M／INAOE，LREC-COLING 2024](https://aclanthology.org/2024.lrec-main.1432.pdf) | 74犬；个体识别49.95%、品种62.28%；四类情境62.18%，多数类基线56.37% | ✅论文报告；情境测试按犬分组，主要三类犬种，不是约70%的情绪或意图翻译 |
| [Whistle FilterNet，Animals 2021](https://doi.org/10.3390/ani11061549) | 抓挠、舔舐、进食等行为分类；原记录抓挠灵敏度87%、特异性99.7% | 行为指标不能当疾病诊断性能；具体应用需检查验证集、混淆项和外部测试 |
| 猫叫三情境分类 | 原仓库二手材料记21猫、最高96% | ❓原论文和数据划分待追溯，暂不作已核实性能锚点 |
| 猫疼痛量表与CatsMe!／Tably | 量表研究与自动化产品是两种证据 | 量表有效性不自动证明App；95%+为厂商／媒体口径⚠️，测试条件待核 |

## 2. “翻译”的边界

现有资料不足以支持把犬猫自然叫声稳定、逐句翻译成人类语言。流畅句子不能当意义已验证；应收窄到明确场景、可观察标签和可拒答的假设。

“尚无足够证据支持逐句翻译”不等于证明犬猫没有任何组合结构，也不等于未来语义研究不可能。喵叫演化、语法与意义的强断言需要原始研究，不再依据概括性转述写成✅。

MeowTalk的90%／约70%与萌小译94.6%／用户自评30–50%未建立可比测试口径，不能作为数值反证，更不能据此证明“缺反馈闭环导致性能差”。保留作宣传与用户反馈线索。

## 3. 按钮交流与反向信号

[PLOS ONE 2024](https://doi.org/10.1371/journal.pone.0307189)支持受训犬把部分按钮词与现实结果关联；[Scientific Reports 2024](https://www.nature.com/articles/s41598-024-79517-6)报告双按钮组合非随机。不能外推为所有犬的开放式语义表达，也不能把每次按压视为真实意图标签。记录训练选择、主人报告偏差与论文披露的商业关系。

Andics 2016等词与语调研究可作为反向通道背景；具体脑区表述和工程效果仍须核对原文。神经机制不替代标准化提示音、录音指令或训练产品的干预效果验证。

## 4. 本项目需要检验的判断

- 明确场景的行为／生理监测有研究基础；家庭泛化、误报和实际行动价值分别评价。
- ①感知＋③推理值得研究，但“性价比最高”尚未建立；与规则阈值、单模态和无AI替代方案比较。
- 主人反馈是可规模化的弱标签来源之一；结合录像、可观察事件、独立行为编码和专业确认，避免模型提示诱导标注。
- 置信度须经测试校准，不能把LLM自述把握程度当统计概率。未知、拒答和观察建议应可见。
