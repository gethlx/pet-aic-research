# 产品专家 · 宠物项目设计起点建议 v2（起点需求重选）

> 提交者：产品专家（Grok bot，云端）｜2026-11-16（洛杉矶）｜基线 分支 chanpin/design-starting-point `4aa59f9`（main `33dadd5`）｜证据档位 B（仓内引用写文件和行号；外部来源写链接和访问日期；标「推断」的是我的判断，未验证）

**结论：最先该满足的需求是「主人在家、日常相处时，想知道它此刻想要什么、在表达什么」。产品给几个可能、最强的替代解释、凭的是哪个画面或声音，再给一个马上能试的小动作让主人自己确认。它每天都用得上，不需要先出事。「不在家时它今天过得怎样」排第二，要等录像能不能拿到查清楚以后再说。全部只到纸面。**

## 先复述晶晶的方向和这次的回复

- 方向不变：A 的形态没定，按「用户需求 → 市场情况 → 技术可行性」从第一性原理推，竞品和调研只当证据（11-15 晚）。核心价值是让主人更懂宠物：意图推断，给带把握程度的猜测；不是翻译，不是健康监测；在家不在家都算（[README](README.md) 第 6–7 行）。A 只做狗（[10-22 讨论结论](2026-10-22-宠物组讨论结论与下周调研要求.md) 第 34 行）。数据口径按 10-22 定论，11-02 起暂不采购。A 仍暂停，不授权测试集、试点、开发、对外能力声明。
- 晶晶 11-16 对 v1 的回复（老邪转）：
  1. 不认可先做行为问题复盘（v1 方向丙）。它可能是痛点，但频率不高，没出严重后果时主人诉求也不强。像打疫苗：没痛过的主人，会为偶发、低频的事买单吗？要重新找最先该满足的需求。
  2. 敢说「你可能看错了」，但要客气、有画面依据。已定，写成产品原则。
  3. 接受不造硬件，先查清能不能拿到主人已有的录像。已定，列成待查项。

**v1 → v2 改了什么：** 起点从「出了问题时」改成「没出事的日常」。v1 的丙降为「有了日常用户以后，出问题时顺带能用」的延伸，不再当起点。v1 的乙（纠正误读）从候选方向改为产品原则。新增录像获取的查法。

## 一、候选需求

按「没出事的日子里会不会冒出来」排在前面，覆盖日常高频的几种。

| # | 需求（大白话） | 什么时候冒出来 |
|---|---|---|
| R1 | 它现在盯着我、蹭我、叫、在门口转，**它想要什么** | 主人在家，每天的相处中 |
| R2 | 我不在家时，**它今天过得怎么样**，有没有在等我、闷不闷 | 主人出门的每一天 |
| R3 | 它今天的状态**和平时一样吗**（精神、情绪、作息，只比行为，不判断健康） | 日常，偶尔觉得「它今天怪怪的」时更强 |
| R4 | **它是不是也在乎我**，我们关系好不好 | 日常，情绪性的 |
| R5 | 它出了行为问题（叫、拆家、乱尿），**为什么、要不要管**（v1 的丙） | 出问题以后 |
| — | 它是不是病了 | 不归 A（健康监测），只列出来说明边界 |

「有证据」后面附出处；没有出处的都是「推断」。

| 需求 | 使用频率 | 诉求强度 | 付费或使用意愿 | 零事故时用得上吗 |
|---|---|---|---|---|
| R1 此刻想要什么 | 推断：每天多次（每次它来找你都可能冒出来）。没有频率数据 | 有证据，但少且弱：主人原话「它盯着我等我做什么，我不知道是什么」「不知道它要什么，快把我逼疯了」（[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 8、13–14 行，检索摘要，未核日期）；中文原话 0 条（同文件第 44 行） | 有证据：为「懂它在想什么」付过钱的人不少——海外 PettiChat 众筹 HK$1,221,069 原始页直读（[市场洞察](../../market/insights.md) 第 9、31 行）；萌小译 799 元预售（[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 23 行）；翻译器 App 订阅扣费成簇投诉，说明有人付了订阅（[市场洞察](../../market/insights.md) 第 19 行）。反面也有证据：因不准而弃用、「试用即卸」（同文件第 19、23 行） | 有证据：翻译器的使用场景就是日常（澎湃个案里主人日常用它，撒娇被误读成「要出门」，[市场洞察](../../market/insights.md) 第 23 行）；这些付费都发生在没出事的时候 |

| R3 状态和平时一样吗 | 推断：日常，但多数日子「一样」，用户感知不到价值 | 有证据，但几乎都在健康侧：数据看不懂反而焦虑（Z1，[用户证据 v0](产品专家-用户证据v0.md) 第 101 行）；变化渐进、事后才察觉（M2，同文件第 128 行） | 有证据（健康侧）：健康项圈有人付订阅，也有人嫌贵、嫌不准（同文件第 26、113 行）。行为侧推断 | 推断：用得上，但很容易滑向健康监测，越界风险大 |
| R4 它在乎我吗 | 推断：日常 | 推断为主：只有评论者观点和厂商精选好评（[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 10、16、30 行） | 有证据（间接）：58% 的养宠人把宠物当家人（武汉市商务局转述白皮书，见 v1 证据块）；翻译器有人「明知是娱乐仍觉得更亲近」（厂商精选评价，偏差大，同文件第 30 行） | 推断：用得上 |

**表的摘要：** R1 和 R2 是唯二「频率高、零事故也用得上」的。R1 的付费证据最直接（翻译器卖出去了），诉求证据最弱；R2 的使用证据最多，但「看到」已被便宜摄像头满足，用户不愿为订阅付费。R3 越界风险大，R4 证据太弱，R5 就是晶晶说的疫苗问题。

## 三、推荐起点：R1「它此刻想要什么」

### 有证据的理由

1. **没出事的日子里，已经有人为这件事付钱。** 这正面回答「疫苗」质疑：疫苗的问题是没痛过的人不买，而「懂它在想什么」不是预防，是好奇和亲近，平常就有。海外 PettiChat 众筹原始页直读 HK$1,221,069（[市场洞察](../../market/insights.md) 第 9 行）；翻译器 App 有人付了订阅（同文件第 19 行）。这些钱都不是出事以后才花的。
2. **市场正好在这里塌了。** 翻译器被骂智商税，有投诉直指「根本没有翻译功能」（[市场洞察](../../market/insights.md) 第 19 行；[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 20–27 行），个案里因乱译弃用（[市场洞察](../../market/insights.md) 第 23 行）。需求被证明了，诚实的供给没有。
3. **它就是 A 的核心价值本身。** 意图推断、带把握的猜测，直接落在「此刻想要什么」上，不用绕。
4. **主人也会看错**：愧疚脸主要是对主人责骂的反应（Horowitz 2009，见 v1 证据块）；主人间的判断一致度低于非主人（[研究周记](../../research/updates-log.md) 第 228 行）。所以「帮你看懂」有真实空间，不只是「替你说出来」。

### 推断的理由

1. **频率最高**：主人在家时，狗每天会多次来找人，每次都是一次使用机会。没有数据。
2. **不依赖还没查清的录像获取**：主人在场，用手机随手拍几秒就够，不用等别家摄像头开放（录像待查项见第六节）。R2 要等那一项查清。
3. **能长出 R2 和 R5**：同一套「看动作和声音、给几个可能和把握」的能力，录像拿得到时可以做「今天它过得怎样、在等什么」；真出了行为问题时也能用。先做日常，出事时才有用户在。
4. **主人每次试小动作，都是一次真实反馈**，可以作上线后的增量数据（符合 10-22「用户侧采集只作增量」）。

### 和竞品的本质区别

- 翻译器（萌小译/PettiChat、各类翻译 App）卖的是「狗的话」加一个准确率，本质是替狗说一句话。
- Traini 最接近：一句话加置信度，有「主人点对/不对」确认回路（[懂宠物竞品 v0](竞品观察员-懂宠物竞品v0.md) 第 2、12 行）。它的确认回路会顺着主人。
- 我们解决的问题不同：不是给答案，是帮主人**更快、更准地自己找到答案**。具体是三件事：给两三个可能和最强的替代解释，而不是一句话；说清凭的是哪个画面或声音；给一个马上能试的小动作（比如「走到门口看它跟不跟」）。主人判断明显不对时，按产品原则客气地说出来。
- 坦白：这个区别目前是推断，Traini 的形态很近，区别能不能被主人感知到，是要验证的。

### 最可能失败的假设（按危险程度排）

| # | 假设 | 为什么可能失败 | 停止条件 |
|---|---|---|---|
| F1 | 产品给的可能，比主人自己已经知道的多 | 主人对自家狗的日常请求（要出门、要吃）往往已经很熟，猜测可能没有增量（推断） | 纸面推演里，多数情况给不出比主人常识更具体的可能：停 |
| F2 | 不自采数据也能给出靠谱的日常意图猜测 | 公开数据没有「等人、想出门」这类家庭意图标签（[README](README.md) 第 18 行）；通用模型在犬情绪任务上接近随机（[11-09 评审](../../reports/2026-11-09-调研评审与频率调整建议.md) 第 17 行）；架构师给的上限是粗猜加三档把握（[不自采技术路径](架构师-A不自采数据技术路径v0.md) 第 5–6 行） | 常见请求里，有可观察线索（位置、朝向、叫声、时间）可依据的占不到多数：只做「看得见的事实 + 主人可试的动作」，不做意图猜测；若连这也撑不住，停 |
| F3 | 主人真的天天在琢磨「它要什么」 | 原话只有 3 条且是检索摘要（[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 8–15 行）；翻译器买家可能买的是好玩，不是困惑（同文件第 30–31 行） | 12-07 前仍找不到主人日常困惑的原话（中外都算）：停在纸面，回头重选 |
| F4 | 能和翻译器区分开，不被当成又一个智商税 | 品类污名已经形成（[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 37 行） | 推断，暂无低成本验证办法；作为风险挂着 |

**低成本纸面验证（不派新调研）：** 用仓内已有的主人原话（[意图理解需求 v0](产品专家-意图理解需求v0.md) 第 8–15 行、[A 用户证据 v0](产品专家-A用户证据v0.md) 第 36–39 行），对照行为学常识，逐条写出产品会给的可能、依据和小动作，自己检查有没有比帖子下面的回复多出东西（对应 F1、F2）。11-30 轮本来就在收的主人原帖可以顺带看 F3。

## 四、产品原则（已定）

**敢说「你可能看错了」，但要客气、要有画面依据。**（晶晶 11-16 定）

- 只在有看得见的依据时才说，并指出是哪一段画面或声音。
- 语气是「这更像是……，因为……」，不是「你错了」。
- 依据不足时宁可说「看不出来」，不硬猜，也不顺着主人。

## 五、排第二和不推荐的

- **R2 不在家今天过得怎样**：排第二。频率高、零事故用得上，但「看到」已被满足，我们只能做「看懂」那层，而且要先拿到录像。等第六节查清再定。
- **R3 状态和平时一样吗**：不推荐当起点，离健康监测太近。
- **R4 它在乎我吗**：证据太弱，不单列；留意 R1 里是否自然带出这份情绪。
- **R5 行为问题**：不当起点（晶晶 11-16 定）。作为 R1/R2 有用户以后的延伸。

## 六、待查项：能不能拿到主人已有的录像（只写查法，不派人，不在本文查完）

**要回答的问题：** 主人已有的摄像头或手机里的视频，我们能不能在主人同意下拿到，拿到要多麻烦、要不要钱、条款允不允许。

**查哪些：**

| 对象 | 为什么查它 |
|---|---|
| 小米（米家摄像头） | 国内出货量大（作者转引 IDC，未核，[A 用户证据 v0](产品专家-A用户证据v0.md) 第 56 行）；仓内已知「每日故事」要云存储（同文件第 54 行） |
| 萤石 | 国内主流，已有「宠物检测」（[A 竞品 v0](竞品观察员-A竞品v0.md) 第 13 行） |
| TP-Link（国内普联、海外 Tapo） | 海外宠物摄像头榜上以本地存储为卖点（[市场洞察](../../market/insights.md) 第 17 行） |
| 涂鸦 | 大量贴牌摄像头用它的平台，查一家等于查一批（推断） |
| 宠物专用机（如 Furbo、Petcube、霍曼、小佩） | 宠物主人用得多；霍曼已知无本地回看、须云订阅（[市场洞察](../../market/insights.md) 第 18 行） |
| 手机相册（iOS、安卓） | R1 起点直接靠它：主人随手拍的视频 |

**每家查什么（逐项记「有 / 无 / 查不到」）：**

1. **存储卡或 NAS**：支不支持本地存储卡；卡里的文件主人能不能直接拷出来、是什么格式；支不支持存到 NAS 或电脑。
2. **App 内导出和分享**：能不能把一段录像下载到手机或分享出去；单段时长上限；是否要会员。
3. **云存储**：云录像能不能下载；保留几天；要不要订阅、价格是否公开。
4. **开放接口**：有没有开发者平台或开放接口能读录像或实时画面；支不支持 RTSP、ONVIF 这类通用协议；要不要申请资质。
5. **条款**：用户协议和隐私政策是否允许主人把录像交给第三方；接口条款是否限制用途。
6. **手机相册**：系统是否允许 App 读主人选中的视频；只读选中的，还是要整个相册权限。

**到哪查：** 官方帮助中心和产品说明书；开发者平台文档；用户协议和隐私政策原文；主流电商的商品页参数。只读公开页面，不登录、不买设备、不联系厂商（同 10-22 调研纪律，[10-22 讨论结论](2026-10-22-宠物组讨论结论与下周调研要求.md) 第 48 行）。官方页面查不到的，写「查不到」，不推测。

**判定标准（每家定一个等级）：**

| 等级 | 含义 | 对 R2 意味着 |
|---|---|---|
| 一级 自动 | 有开放接口或通用协议，主人授权一次后能持续读 | R2 可做，体验好 |
| 二级 半自动 | 录像能自动落到存储卡、NAS 或电脑，我们读文件 | R2 可做，但要主人会设置 |
| 三级 手动 | 只能在 App 里一段段导出或分享 | 只够偶尔用，撑不起每天的「今天过得怎样」 |
| 不可 | 只能在厂商 App 或云里看，或条款禁止 | 这家用户做不了 |

另外两个附加判定：要不要额外付订阅；条款是否允许。任何一项为否，等级降一级记。

**怎么用结果：** 主流几家多数在一、二级，R2 可以进入下一轮讨论；多数在三级或不可，R2 只能等，或换「手机随手拍」路线。R1 只依赖手机相册，不受影响。

## 七、要晶晶拍板的点（最多 3 件）

1. **起点定为「在家时，它此刻想要什么」，你同意吗？** 理由是它天天用得上、平常就有人愿意花钱（翻译器卖出去了），也正好是我们说的「更懂它」。代价是技术最没底，也最容易被当成又一个翻译器。
2. **「不在家时它今天过得怎样」排第二、等录像查清再说，可以吗？** 还是你觉得它应该和第一条并列？
3. **12-07 前如果还是找不到国内主人「不知道它要什么」的原话，能不能先用海外原话推进纸面设计？** 不能的话，这个起点就停在纸面等证据。

## 不做什么
