## Q：有没有哪家把项圈和摄像头结合起来，用画面解释项圈报的异常？
结论：没找到"用画面解释项圈异常"的公开说法；但 Petcube 已经把摄像头和 GPS/活动追踪器放进同一个 App，是最近的对手。
- Petcube 同时卖摄像头和 GPS Tracker，追踪器在 Petcube App 里做 Daily Activity / Active Minutes。https://petcube.com/tracker ; https://petcube.com
- Petcube App（Google Play）描述：在宠物日志里记录活动、作息、健康数据和日常片段，带智能提醒。https://play.google.com/store/apps/details?id=com.petcube.android
- Petcube Facebook 帖子："先用一个摄像头，以后加互动或 GPS，不用学新系统"。https://www.facebook.com/petcube.inc/posts/health-checks-activity-tracking-and-ai-guidance-petcube-app-understands-your-pet/1442727003865447 （发布日期未读到）
- PetPace：生理指标项圈，宣称 11 项指标、学习个体正常值、免费 24/7 兽医。无摄像头。https://petpace.com
- 待核：Petcube 是否把追踪器数据和视频在时间线上关联、是否有跨设备提醒；Furbo、Tractive、Whistle、Fi 是否有互通。

## 定位与话术建议
- 竞品话术偏满：PetPace "唯一测真实生命体征"、发作前预警；Traini "最高 94%"。
- 我方口径：不用"预警/诊断/准确率"；只说"跟它自己平时比，变了多少、持续几天，下一步可以怎么做"。原型若能测出并公开误报率，可作竞品给不出的证据。
