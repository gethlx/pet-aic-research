# 架构师 · A 意图/情绪识别 开源资源调研 v0（仅调研，不含方案）
检索日期：2026-10-13。⚠️ = 未逐条打开原文/许可证核对。
更新 2026-10-22：DogFLW（CC BY-NC 4.0，改编物也只能非商用）、CREMD（仅学术、禁止商用）的许可已由核查员打开原文核实。

## 结论先行
- 能商用的主要是**代码/基座**（Wav2Vec2 Apache-2.0、MMPose 等），**带"意图/情绪/情境"标签的狗数据几乎都不能商用或许可不明**。
- 现有标签全是**人推断的情境或情绪**，不是狗真实意图；没有"等人/无聊/想出门/焦虑"这类家庭意图标签的数据集。
- 天花板低：人听叫声猜情境约 39% vs 机器 43%（6 类情境，Pongrácz 系）；犬吠四任务最高 62.18%（多数类基线 56.37%，四类均为陌生人在场，性别任务未超基线 68.70%）；面部情绪 71%～89% 只在实验室单品种二分类成立。

## 能推断到什么程度（天花板证据）
- 人类听叫声猜情境≈39%，机器 43%（6 类）→ 叫声单模态天花板低。
- 认证编码员之间部分面部动作单元也不一致（Bremhorst 2019）。
- 众包情绪标注一致度只有 0.69～0.75，**主人一致度反而低于非主人**，专业人员较高（CREMD）。
- 89% 仅为实验室、单品种、二分类；没有任何家用场景、多类意图的验证。

## 缺口
1. 无可商用的狗情绪/意图标注数据；面部和多模态数据都是 NC 或许可不明。
2. 无"等人、无聊、想出门、焦虑"等家庭意图标签；现有标签都是实验情境或人的感知。
3. 无家用机位、夜视、带家庭情境（时间、主人在不在、门铃）的多模态数据。
4. 尾巴摆动、"BARK"类数据本轮未找到，待补查。
