# 架构师 · A 意图/情绪识别 开源资源调研 v0（仅调研，不含方案）
检索日期：2026-10-13。⚠️ = 未逐条打开原文/许可证核对。

## 结论先行
- 能商用的主要是**代码/基座**（Wav2Vec2 Apache-2.0、MMPose 等），**带"意图/情绪/情境"标签的狗数据几乎都不能商用或许可不明**。
- 本轮定位的相关标签主要为实验情境或人类感知情绪，不能直接当作犬真实意图；本轮未定位到经独立验证的"等人/无聊/想出门/焦虑"家庭意图数据，不等于证明此类资源不存在。
- 下列历史成绩来自不同任务与测试条件，不构成统一精度或技术天花板；是否适用家庭场景须看标签、动物／家庭隔离与外部实验。

## 能推断到什么程度（现有任务证据，不是天花板）
- 上述人类与机器历史成绩仅适用于其各自研究，不能据此推出单模态能力上限。
- 认证编码员之间部分面部动作单元也不一致（Bremhorst 2019）。
- 众包情绪标注一致度只有 0.69～0.75，**主人一致度反而低于非主人**，专业人员较高（CREMD）。
- 上述89%限于该实验室、品种和二分类；本轮未定位到足以支持家庭多类意图的验证。

## 缺口
1. 本轮所列犬情绪／意图数据多为NC或许可不明；逐版本许可与来源再授权仍待核，不对全球可用数据作穷尽判断。
2. 本轮未定位到经独立验证的家庭意图标签；实验情境和人类感知须分别记录。
3. 家用机位、夜视及家庭上下文的多模态资源仍需继续检索与核验。
4. 尾巴摆动、"BARK"类数据本轮未找到，待补查。
