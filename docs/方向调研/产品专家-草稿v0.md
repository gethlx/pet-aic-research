# 方向预设 草稿 v0（产品专家起草，待架构师补技术可行性）
原则：只基于仓库现有调研 + 群内已核信息；未核数字不写。每个方向都要能被后续深挖证伪。

## 方向 A：独处行为观察与异常解释（视觉为主）
- 用户/场景：白天上班、狗独自在家的城市主人（U1）；想知道"今天有没有异常、为什么"。
- 产品形态：接入已有家用摄像头 → 异常片段 + 候选解释 + 不确定标签 + 主人反馈。
- 技术层：①感知（视频行为检测）+ ③推理（解释/拒答）。
- 已知证据：规则+检测有先例但仅实验室 2 犬（Atif 2023, Sensors, doi:10.3390/s23062892，核查员转述待复核）；家中独处视频几乎无可商用公开数据（核查员 grok-dataset.md）；Furbo/Petcube 已卖 AI 提醒+Daily Diary（竞品观察员 cameras.md，待截图复核）。
- 关键未知：差异化是否只剩"解释"；数据从哪来；普通犬（非分离问题犬）异常基线频率。

## 方向 B：老年/慢病宠物的夜间与健康变化监测（可穿戴/生理为主）
- 用户/场景：老年犬、短鼻犬、慢病宠物主人（U2）；担心夜间呼吸/睡眠/活动异常。
- 产品形态：项圈或床垫传感 → 趋势与偏离提醒 → 供兽医复看的记录。
- 技术层：①感知（IMU/心率/呼吸）+ 趋势模型，弱依赖 LLM。
- 已知证据：Whistle 抓挠灵敏度 87%/特异性 99.7%（docs/02，doi:10.3390/ani11061549）；Invoxia 宣称心率/HRV/呼吸率、健康监测免订阅（#8，厂商自报）；Whistle 原服务已停用（docs/03 §①）。
- 关键未知：家用传感对毛发/运动伪影的鲁棒性；主人是否愿意持续佩戴；与兽医流程如何衔接。

## 方向 C：按钮板/主人主动交流的理解辅助（交互为主）
- 用户/场景：已在用按钮板的 AIC 爱好者（U4），小众但高投入。
- 产品形态：记录按压序列+上下文 → 帮主人复盘"它可能想表达什么"，并提示证据强弱。
- 技术层：②交互记录 + ③推理。
- 已知证据：按钮词义理解研究（Bastos 等, PLOS ONE 2024, doi:10.1371/journal.pone.0307189，#11）；按压≠真实意图（docs/02 §3）。
- 关键未知：人群规模；能否做出比主人自己复盘更有用的东西。

## 已排除/降级
- 声学"翻译"：犬吠情境仅比多数类基线高 5.8pp，且四类均为陌生人在场（#10）→ 降为 A/B 的辅助信号，不单独成方向。

## 用户研究视角（产品专家下一步）
对每个方向补真实痛点证据：社区讨论（小红书/Reddit/豆瓣）、竞品差评、兽医视角。暂不做访谈招募，只做二手证据收集。
