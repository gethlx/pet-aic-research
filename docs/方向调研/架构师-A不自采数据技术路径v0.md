# 架构师 · A 在「不自采训练数据」约束下的技术路径 v0（仅调研）

前提（晶晶 2026-10-21）：无资源/成本自采训练数据。路径限：开源观察、付费采购、许可内深加工/合成。不做健康监测；意图推断带不确定度；在家不在家都用。

## 结论先行
在不自采的前提下，**可卖产品目前撑不到「稳定识别家庭日常意图」**；最多撑到「事件触发的粗粒度情境/情绪猜测 + 每条猜测可回看画面 + 三级把握与备择解释」。三类数据源能撑到的台阶不同。

## 三档能撑到哪

| 档 | 数据来源 | 能撑到 | 撑不到 | 阻塞 |
|---|---|---|---|---|
| A1 许可允许的开源 | Wav2Vec2 / MMPose 等基座；动作类若许可 OK | 特征抽取、姿态/叫声表示、研究原型演示 | 家庭意图分类器（无人标「等人/无聊/想出门」的可商用集） | DogFLW 已核 CC BY-NC 4.0、CREMD 已核仅学术（核查员 2026-10-22 开原文）；意图标签本身缺失 |
| A2 付费可商用数据 | 采购后授权明确可卖产品 | 若库里有家犬情境/行为标签：可训粗粒度「情境/情绪」模型作产品内猜测 | 若库仍是实验室/动作标签：同上，补不了家庭意图 | **尚未摸到候选库、价格、商用条款**（下周必查） |
| A3 多源混合 + AI 合成（研发期，含 NC/仅学术源） | 开源+采购+学术数据深加工、合成 | 研发期训练与验证粗猜模型、扩增样本、测管线和盲评流程 | 生不出源数据没有的意图类；商用前受限源训出的模型多半要重训 | 每条样本记来源与许可，商用前剔除重训 |

## 推荐产品形态（在数据约束下）
1. **规则 + 情境支架为主，学习模型为辅**：门铃、烟花、出门准备等可观测事件 → 带把握的粗猜（偏警戒/偏兴奋等），不报准确率。
2. **每条猜测绑定片段**：可回看画面；写法参考 Wayenberg 式「最强备择解释 + 三级把握」（未验证，作方法参考）。
3. **模型层**：开源基座做特征；有 A2 可商用标签再训头；无 A2 则不做「意图识别模型」卖点，避免空转。
4. **数据**：研发期以采购数据 + 多源混合合成为主，不因许可屏蔽；用户侧采集作后续补充，不当冷启动主数据。商用前按许可标签处理并提醒晶晶。

## 下周要核清才能改结论的事
1. ~~DogFLW、CREMD 许可原文~~ 已由核查员 2026-10-22 核实：均不可商用，衍生与训练同受限。
2. 有无可采购、授权可商用、带家犬情境或意图类标签的付费库（有则 A2 上台阶；无则长期停在 A1 产品形态）。
3. ICASSP 2025「人声预训练迁移动物叫声」全文许可与可复现范围（选型参考，摘要级不够）。

## 不做什么
不写实现方案、不选型落地、不引入未确认的付费采购。

## 更新 2026-10-22（晶晶定论）
- 研发阶段：开源（含 NC/仅学术）＋多源混合＋AI 合成＋采购数据可一起用，不因许可屏蔽；选数据以低成本、高质量可信为主。
- 商用前：由架构师提醒晶晶处理许可（替换/重训/授权）。
- 用户侧采集：鼓励并纳入设计，但不作为冷启动建模主数据。
- 架构要求：每条样本记录来源与许可标签，模型记录训练数据清单，便于商用前剔除受限数据重训。
