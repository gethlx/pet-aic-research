## 二、本期有价值的发现

### 1. ICASSP 的方法核查值得保留

报告补读了论文方法和结果表，明确犬任务采用随机 70:20:10 切分，未报告按犬隔离。表三犬任务 AVES 的 UAR 为 54.23%，语音预训练最佳 Wav2Vec2 为 48.95%，相差 5.28 个百分点。以往笼统的“动物预训练仅边际提升、人声模型已经够用”得到收窄。[论文方法与表三](https://arxiv.org/html/2501.05987v2)

这项补查的实际价值是帮助比较表征路线与评估方法。结果不能作为未见犬泛化、家庭意图识别或产品精度的依据；随机片段切分也不能直接证明发生泄漏，需检查具体分组与数据来源。

作者代码和取得方式被进一步查找，可作为后续工程调查入口；本报告未对全部代码文件的许可适用性作独立审计，也未运行实现。

### 2. 17 犬游戏数据的研究用途更具体

数据的多机位视频、同步音频、个体／场次元数据及两层标注结构已得到补充。[数据记录](https://zenodo.org/records/18972388)与[README](https://zenodo.org/api/records/18972388/files/06%20Readme.txt/content)使其超出“只有一个论文标题”的线索状态。

它有助于观察受控互动中声音、行为与上下文的关系，仍不能代表一般家庭环境、所有年龄犬或真实意图标签。研究价值与许可声明冲突应分别记录；本报告下文要求恢复冲突状态，不否定其研究参考价值。

### 3. 竞品主体与宣称来源开始得到拆解

市场报告回查 Kickstarter 等原始页面，并将“美国 PettiChat 由 Traini 运营”收窄；同时调查萌小译宣传的公开学术数据来源。这比继续堆叠多家转载更有价值。

但页面显示创建者品牌，并不自动闭合品牌、网站、法律实体、投资方之间的关系。新的“Traini 是投资方”仍是二手单源线索，不能因旧运营方说法不可靠就认定新说法成立。引用 DogSpeak 等论文，也不等于已证明产品用其训练或通过同等条件的独立测试。相关内容见[市场周记](../market/updates-log.md)。

### 4. 使用负担与服务条件提供了研究入口

市场材料涉及佩戴不适、预期落差、退货及订阅条件。这些问题可转化为下一期“主人如何处理、是否持续使用”的检索问题。财务原文回查和服务条款有助于厘清资料口径，但对当前需求判断的直接贡献小于实际使用证据。

SoundTalks、Ouren M1 等可以保留为产业与产品线索。厂商 ROI、健康功能和“行为数据平台”叙事，不等于商业闭环或家庭效果已经被独立验证；畜牧结果不能直接迁移到家庭犬场景。

## 三、需要纠正的事实与证据问题

### 问题 1：Zenodo 许可冲突被错误关闭——优先纠正

**报告原说法：**记录级许可字段已空，README 的 NC 声明“胜出”，许可冲突告破。[原条目](../research/datasets.md)、[研究周记](../research/updates-log.md)

**本轮复查事实：**同一记录 `18972388` 的 API 返回：

```json
{
  "metadata.license.id": "cc-by-4.0",
  "license": null,
  "modified": "2026-05-18T21:40:34.678637+00:00"
}
```

上段按字段路径摘记，不是 API 原始结构；`metadata.license.id` 是实际许可字段，根层 `license` 为空。归档 README 则写 CC BY-NC 4.0。[API 原始记录](https://zenodo.org/api/records/18972388)、[README 原文](https://zenodo.org/api/records/18972388/files/06%20Readme.txt/content)

**分析：**当前两处声明仍冲突。取错字段层级是合理怀疑，但未取得扫描当时的完整原始响应，不能认定其具体读取实现或过去每个时点的状态。即使选择更保守的使用方式，也不能据此宣布冲突已解决，更不能外推“受控采集犬声数据均无商用许可”。

**整改：**数据表、周记与账本恢复“声明冲突待核”，分别列出处、版本和读取日期。项目的数据研究取向保持不变，不必把许可争议继续当作研究方向的主问题。

### 问题 2：Text to Bark 被当成商用合成信号——优先撤回推断

**报告原说法：**文字转犬吠商用合成的首个信号，并转述“95% 的狗无法区分”。

**原始依据：**ElevenLabs 官方文章发布于 2025-04-01，文中使用“2-Factor Pawthentication”等明显玩笑措辞；没有可核的样本、测试方案或研究结果出处。[官方文章](https://elevenlabs.io/blog/text-to-bark)

**判断与限制：**根据日期和内容，本审核判断它具有愚人节营销性质。未独立证实厂家是否另有实际演示或服务，不能据此断言任何形式的产品都不存在；但该文章不足以支持商业可用性，更不足以支持合成数据对真实识别任务有效。

**整改：**撤回“首个商用合成信号”和“95%”效果依据，保留营销材料身份或移入筛除记录。下一轮找真实测试集上的对照增益，避免继续追问这条营销数字。

### 问题 3：OSF 项目记录被列为预印本——纠正体裁

**报告原说法：**OSF Preprints、预印本待评审，作为本轮新增论文。

**原始依据：**DOI `10.17605/osf.io/98nhd` 的 DataCite 登记中，具体 `resourceType` 为 `Project`。摘要写明收集了 53 场音视频、17 只犬拒绝参与，分析仍在进行。[DOI 登记](https://api.datacite.org/dois/10.17605/osf.io/98nhd)

**分析：**一些通用引用字段也将对象归入文章类，不能替代具体资源体裁。该记录能证明有第二团队开展相关研究，尚未证明可取得预印本正文、公开数据或完成分析。53 场次和 17 只退出犬也不能直接当作最终有效独立犬样本。

**整改：**改为“OSF 项目记录，结果与数据取得状态待核”，保留其资源地图价值。若后续定位到单独论文，再按论文实际状态记录。

### 问题 4：Salford“98.1% 一致度”缺少可定位来源——降级待核

周记没有给出题名、作者、年份、原始链接或页码，无法判断评价的是动作类别、游戏情境还是情绪，也无法核对样本、对照及分歧处理顺序。

因此，当前不能用这个数字论证主人标注可靠或确认回路有效。这不是认定论文或数字虚假，而是其记录不足以复核。[线索所在周记](../research/updates-log.md)

**整改：**先补原文定位，再核方法；若不能取得，保留未核线索，撤去确定性支持语句。即便数字属实，也需区分独立初判一致度与双方回看后协商一致，后者不等于独立准确性。

### 问题 5：有限查询被扩大为资源不存在或当前状态确定——收窄结论

研究周记将采购盘点概括为“公开渠道无”。实际覆盖记录主要是有限关键词查询与声音素材库，不足以排除家庭视频、互动、行为数据或其他可授权路径。

同样，OpenAlex 未检出 Scientific Data 条目，只能说明本次检索未定位正式发表；数据页曾自述投稿，不足以实时证明仍在审。应分别记录“托管页自述状态”和“本次未查到发表记录”。

**整改：**用“本轮检索未定位到符合要求的资源／发表条目”，同时说明范围；不把有限查询结果作为技术或采购路线的全局结论。

### 1. 市场侧的问题在于使用场景没有成为组织中心

本期媒体转引主要涉及猫的佩戴体验和主人对翻译的评价。它们可提示产品负担，不能回答狗主人在哪些事件中不确定、采取何种行动、普通摄像头或训练为何不够用。评论中自评的“30–50%”不是标准化测试，也不能与实验准确率相减或视为独立验证。

未打开平台原帖的情况已如实记录，这点应保留；问题是不能把“取得媒体转引”总结成国内一手需求已经补齐。正面持续使用、弃用、原有替代办法和付费证据均需补充，单靠负面感受也不能确定市场机会。

### 2. 工程侧的问题在于资源核查代替了能力覆盖

四项追加重点做过查询，可以作为执行动作记录；但许可、源码入口和声音库资料，不能替代对家庭视频理解、时序事件、跨犬／跨家庭验证的调查。下一轮应从具体任务查方法，允许没有合格候选，避免继续以犬吠检索代表整个家庭理解方向。

### 3. 存量推断仍需收窄

`market/insights.md` 沿用“资本背书使提价压力只增不减”等判断。投资和收购事实可以支持继续观察服务风险，不能证明特定产品未来一定提价。SoundTalks 的产业部署自报也不能直接证明家庭应用的商业闭环。

这些属于本期仍在使用的分析风险，不应全部归为本周新引入的错误。相关段落应回到已观察变化、出处和未知条件，减少因果外推。

本报告没有擅自回退或推进扫描水位。后续采用何种窗口，应在周记明确记录依据；错误结论和未完成主题继续放入现有待办，不因时间窗口更新而丢失。已有正确材料无需每轮重新全量检索。
