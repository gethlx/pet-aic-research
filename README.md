## 这是什么

本仓库系统梳理「AI 理解宠物 / 人宠增强交流」方向的产品实践与学术证据，回答三个问题：

1. 用 AI 理解宠物行为，本质是什么？（多模态模式识别）
2. 哪些明确任务已有证据，哪些“翻译”或意图宣称尚未验证？
3. 哪些技术路线**真正可落地**、有哪些已发表证据？（四层路线框架）

**研究立场：** 目标不是「狗语翻译机」，而是**人宠增强交流**——在人与宠物已有的训练/条件反射式交流基础上，用 AI 增强：传达模糊诉求与情绪表达、猜测和分析意图。AI 的角色是**副驾驶**（提假设、排优先级），决断权在主人。

## 核心结论（TL;DR）

> 建仓资料截至2026-10-01；本轮复核指定原始依据，未穷尽全景。来源与纠正范围见 [参考资料](./docs/04-references.md)。

| 问题 | 结论 |
|---|---|
| AI 理解宠物 = 多模态模式识别？ | **是。** 声学/视觉/生理/上下文四路输入 → 分类、回归、异常检测，叠加个体生理基线 |
| 语义级「语言翻译」可行？ | **现有证据不足以支持稳定逐句翻译。** 这不等于证明动物不存在语义或组合结构 |
| 明确任务的识别可行？ | **部分任务有研究结果。** 犬吠四类情境62.18%（多数类基线56.37%）；行为、情绪、意图和疾病预警分别验证。猫叫96%仍待追溯原论文 |
| 「增强交流」路线可行？ | **有研究基础，产品价值待验证。** 按钮关联与非随机组合有论文，不能直接当开放式语言能力或无偏意图标签 |

## 四层技术路线

```
① 感知层   AI 读宠物      行为/生理/声学分类 + 个体基线 → 异常候选         [部分明确任务已有验证]
② 表达层   训练界面       按钮板/触屏 AIC 界面 + 训练科学                 [关联与组合研究，边界明确]
③ 推理层   意图假设引擎   多模态融合 + LLM 假设 + 主人反馈闭环            [分类可行·闭环待验证]
④ 反向层   人 → 宠信号    语调/提示音/条件反射训练标准化                  [机制背景·工程待验证]
```

- **①+③ 是待验证的产品假设**：先比较规则、单模态和LLM的实际增益，再判断投入价值。Whistle的历史科研方法可借鉴，但原商业服务已停用。
- ② 按钮板可研究训练与交互；按压事件不自动代表真实意图，需评估训练负担和标注偏差。
