**Augmented Interspecies Communication (AIC) for Companion Animals — Feasibility & Landscape Research**
**人宠增强交流（AIC）产品方向研究：可行性判断 · 技术路线 · 证据全景**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

## 这是什么

本仓库系统梳理「AI 理解宠物 / 人宠增强交流」方向的产品实践与学术证据，回答三个问题：

1. 用 AI 理解宠物行为，本质是什么？（多模态模式识别）
2. 「猫狗语言翻译」到底可行吗？（状态级可行，语义级不可行）
3. 哪些技术路线**真正可落地**、有哪些已发表证据？（四层路线框架）

**研究立场：** 目标不是「狗语翻译机」，而是**人宠增强交流**——在人与宠物已有的训练/条件反射式交流基础上，用 AI 增强：传达模糊诉求与情绪表达、猜测和分析意图。AI 的角色是**副驾驶**（提假设、排优先级），决断权在主人。

## 核心结论（TL;DR）

> 数据截至 2026-10-01，来源与核实状态见 [docs/04-references.md](./docs/04-references.md)。

| 问题 | 结论 |
|---|---|
| AI 理解宠物 = 多模态模式识别？ | **是。** 声学/视觉/生理/上下文四路输入 → 分类、回归、异常检测，叠加个体生理基线 |
| 语义级「语言翻译」可行？ | **不可行。** 猫狗没有组合式语言（无语法、无无限语义空间）；猫的喵叫是对人类发明的习得信号。任何「逐句翻译」产品输出的是模型的概率脑补 |
| 状态/情绪级解读可行？ | **可行。** 同行评审精度：猫叫情境分类 96%（米兰大学，2019）、犬吠情境约 70%（密歇根大学，2024）、加速度计抓挠检测灵敏度 87%（玛氏 Whistle，2021） |
| 「增强交流」路线可行？ | **可行。** 四层路线中三层有硬证据，表达层（按钮板 AIC）证据最硬（UCSD 2024 两篇） |

## 四层技术路线

```
① 感知层   AI 读宠物      行为/生理/声学分类 + 个体基线 → 健康与情绪预警   [产业级已量产]
② 表达层   让宠物开口     按钮板/触屏 AIC 界面 + 训练科学                 [同行评审 ×2]
③ 推理层   意图假设引擎   多模态融合 + LLM 假设 + 主人反馈闭环            [分类可行·闭环待验证]
④ 反向层   人 → 宠信号    语调/提示音/条件反射训练标准化                  [神经科学支持]
```

- **①+③ 组合是产品性价比最高的路线**：感知层用成熟传感器方案循玛氏验证过的行为分类，推理层做「意图假设 + 反馈闭环」——这是市面「翻译器」类产品（如萌小译）普遍没做对的地方。
- ② 按钮板门槛低、社区验证充分，适合作为低成本切入点获取真实交互数据。

## 证据标注规范

本仓库所有事实性陈述遵循统一标注：

- ✅ **已核实**：多来源交叉验证，或同行评审文献
- ⚠️ **自报**：厂商/团队单方口径，未经独立验证
- ❓ **未确认**：公开渠道无法验证，或来源间存在矛盾
