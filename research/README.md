# research/ · 科学证据与工程资源

回答：具体犬猫场景所需的方法、数据、模型、硬件已验证到什么程度，能否取得和使用。四层路线用于分类，不能代替物种、任务和验证边界。

## 四条资源线

- [papers](papers.md)：论文和线索分组；记录原文、发表状态、样本、任务／标签、指标／基线、个体隔离、外部验证、利益关系和局限。以近年增量为主，允许补关键旧文献、负面结果和简单方案对照。
- [datasets](datasets.md)：模态、动物数／事件数、采集与标注、获取方式；逐版本核对数据许可及商用条件，不以接口开源推定子数据开放。
- [tooling](tooling.md)：固定资源和版本，分别核对代码、权重、数据、依赖许可；记录commit／release日期但不把活跃度当可部署性。
- [supply-chain](supply-chain.md)：具体器件和宠物适配条件、供货／成本、无线与材料／电池安全、目标国家法规；只用公开资料，不录NDA报价。

优先犬猫真实家庭及可靠评估；鸟鲸等为方法参照，跨物种基准不证明犬猫意图。健康研究关注误报、漏报、提前量和实际行动；按钮与主人反馈须查偏差；LLM与规则／单模态比较。不得把行为分类、健康关联、情绪解释及意图推断混为同一精度。
