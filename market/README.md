# market/ · 市场与产品追踪

回答：具体犬猫场景中，什么已在售、被怎样验证、有人持续使用或付费到什么程度。商业信号与科学证据对齐后仍须检验，差距不自动等于机会。

## 范围

M1翻译／交互硬件、M2健康监测硬件、M3声学／视觉软件、M4按钮与训练生态、M5畜牧方法对照。M5只跟里程碑。解决同一需求的非AI用品、自然训练或规则方案可作为功能与成本对照，不仅是价格对照；不扩展成传统用品大全。

## 固定维度

路线标签外同时记录犬／猫、使用场景、产品版本和当前状态。核心维度为传感器、AI方案、宣称与验证、可比性、价格／订阅、商业信号、限定证据标签。依据[VETTING](../VETTING.md)核验；不同口径不相减，不以整行✅掩盖未知。

重要对象补充长期使用／续费、训练负担、退货／误报、数据导出和停服条件；缺公开数据写待核。预售、出货、下载、活跃和付费人数分开。
