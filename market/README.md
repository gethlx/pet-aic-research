# market/ · 市场同类产品对比调研与分析

> 收集章程（charter）。更新频率：每周一次（见仓库根 README）。标注规范沿用全仓约定：✅ 已核实 / ⚠️ 自报 / ❓ 未确认。

## 1. 本文件夹的定位

**market/ 是商业 ground truth。** 它回答的问题是：四层技术路线（感知/表达/推理/反向，见 `docs/03-roadmap.md`）在商业世界里**被验证到什么程度**——什么有人买单、什么被用户骂、精度宣传与实测差多远、商业闭环在哪。

与 `research/` 的分工：research 管「技术上什么被证明」，market 管「商业上什么被验证」。两folder共用四层路线作为分类骨架，同一层可直接对齐「商业进展 vs 学术进展」的差距——**差距即机会**。

## 2. 品类圈（收集范围）

| # | 品类 | 入库理由 |
|---|---|---|
| M1 | AI 宠物翻译/交互硬件 | 竞品正面战场（萌小译、MeowTalk 硬件化等） |
| M2 | 宠物健康监测硬件（穿戴/窝垫/摄像头/猫砂盆） | 感知层主战场（Moonback、PETKIT、CATLINK、Whistle、PetPace 等） |
| M3 | 宠物声学/视觉 AI 软件 App | 轻量竞品与需求探测器（MeowTalk、Tably、CatsMe! 等） |
| M4 | AIC 按钮板与训练生态 | 表达层竞品（FluentPet、Dogosophy Button 等） |
| M5 | 畜牧声学/行为监测（**对照系**） | 已跑通 ROI 的产业镜像（SoundTalks 等），只跟踪里程碑不深拆 |

**排除**：无 AI 成分的传统宠物用品（自动喂食器、普通定位项圈）不入库，除非作为价格带对照组出现；纯山寨贴牌产品只记价格带，不做深度拆解。

## 3. 每案固定维度（保证可比性）

任何产品入库必须按以下七个字段填写，缺项标 `—`：

1. **路线归属**：对应①②③④哪一层（可多选）
2. **传感器方案**：加速度计 / PPG / 毫米波雷达 / 麦克风阵列 / 摄像头 / 重量传感
3. **AI 方案**：自研模型 / 通用大模型 API / 规则引擎（尽量查明）
4. **精度口径**：官方宣称值 vs 独立验证/用户实测值（**落差是最重要的字段**）
5. **价格与商业模式**：硬件一次性 / 订阅 / 数据服务
6. **销量·渠道·融资**：可公开验证的数字，全部标来源与日期
7. **证据等级**：✅⚠️❓

## 4. 文件结构

| 文件 | 内容 | 更新方式 |
|---|---|---|
| `products-matrix.md` | 全品类对比主表（七维度 × 全部产品） | 每周增量更新 |
| `profiles/` | 单品深度拆解（一案一文件，拆到功能边界与口碑证据） | 新品入榜或重大变化时新建/修订 |
| `updates-log.md` | 每周增量日志（新品、融资、口碑变化、下架、价格调整）+ 存疑区 | 每周追加，倒序 |
| `insights.md` | 阶段性分析产出：定位图谱、宣传-实测落差榜、可借鉴/可避坑清单 | 每月或重大变化时重写 |

## 5. 情报来源优先级

1. 行业媒体首发（36氪、猎云网、宠业家、PetAge、PET NEWS 等）
2. 工商/融资数据库（企查查、亿欧、Crunchbase、投中网）
3. 电商公开页与口碑（亚马逊、小红书、抖音评论的抽样，只取可引用的公开内容）
4. 官方渠道（官网、发布会、PR 稿——一律降级为 ⚠️ 自报）

## 6. 更新规则

- **只做增量**：新增行、修订变化字段，不改写历史结论；每次变更在 updates-log 留痕。
- **落差必录**：凡官方精度与用户实测/独立验证出现显著分歧（>20 个百分点），必须在 products-matrix 的落差列与 insights 落差榜同时登记。
- **存疑区**：查不实、来源冲突的信息一律进 updates-log 存疑区，标 ❓，不得写成结论。
